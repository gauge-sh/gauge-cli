# Contributing

Issues are welcome for bug reports, questions, and suggestions. For bugs, include
your CLI version, operating system, and a minimal reproduction.

The Gauge team maintains this repository and is solely responsible for merging
changes. Forking and building your own version is the preferred way to customize
Gauge. We periodically review community changes and may bring them upstream.

See the [README](README.md#development) for build and test instructions.
